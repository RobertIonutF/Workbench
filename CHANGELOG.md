# Changelog

## 0.2.0 — 2026-11-01

- Add reusable model profiles, actual capability probes and comparisons, normalized usage, latency and task budgets.
- Add syntax-highlighted editor tabs, side-by-side diffs, hashed hunk review, comments and follow-up tasks.
- Add file/folder/declaration context, images, PDF text extraction, provenance and project memory.
- Add persisted plans, pause/resume, safe steering, queued turns and conversation forks.
- Add pipeline/parallel agent teams, Git worktree isolation, selected-file commits, integration and explicit GitHub PR publishing.
- Add policy-aware workflow commands, scheduled tasks, notifications, native PTY terminals and tray background mode.
- Add Plugin Studio forms, real tool/resource/prompt trials, saved assertions, traces and model-assisted source generation.
- Add a pinned GitHub plugin catalog with three packaged starter skills and update inspection.
- Add managed local web previews and isolated browser actions/assertions/screenshots/console evidence.
- Add portable encrypted profile backups and restart-safe restoration with a recovery copy.
- Add Ed25519 verified update manifests, digest-checked downloads and an exit-aware installer helper.
- Add Windows CI, deterministic catalog/portable/source packaging and optional certificate-backed Windows signing.
- Harden destination-bound credentials, log redaction, scheduler claims, process cleanup and interrupted-work recovery.

The Windows preview remains Authenticode unsigned unless built with a publisher certificate. Live provider entitlement/inference and clean-machine upgrade/uninstall remain separate from deterministic fixtures and local smoke tests.
