# Workbench

Rust owns runtime, provider requests, credentials, policy, storage, plugins and MCP. React/TypeScript renders a real local API; do not replace backend actions with browser-only mocks.

Keep secrets out of logs, exports and public connection records. Every mutating tool passes through policy. Filesystem tools stay inside the chosen project. Never describe trusted native commands or MCP subprocesses as sandboxed.

Validate with cargo fmt/test/clippy, frontend typecheck/build, actual API integration fixtures, browser workflows and the native desktop build. Real external-account verification is distinct from deterministic fixture tests.

Read README.md, docs/ARCHITECTURE.md and docs/API.md for the architecture and supported contracts. docs/VERIFICATION.md records checks actually completed and their limits.
