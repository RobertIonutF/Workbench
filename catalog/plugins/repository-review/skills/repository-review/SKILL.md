---
name: repository-review
description: "Review a codebase with file references and clear evidence."
---

Inspect the selected project before proposing changes. Read its AGENTS.md and relevant architecture/configuration. Use file and search tools to identify entry points, risky boundaries and existing tests. Distinguish observed defects from improvement suggestions. For each actionable finding cite the project-relative file and line, a concrete trigger, the resulting behavior and a focused correction. Never invent executed tests or successful commands. Request command authority only when a relevant check needs it. Finish with actual verification and remaining uncertainty.
